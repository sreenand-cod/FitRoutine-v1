# 🏋️ FitRoutine

**FitRoutine** is a production-ready fitness website built using **HTML5, CSS3, and Vanilla JavaScript**. It features a premium pixel-art inspired design with responsive layouts, workout tracking, an exercise library, BMI calculator, favourites, dark mode, and local storage support.

The project is lightweight, fast, framework-free, and suitable for deployment on any static hosting platform.

---

# ✨ Features

- 🎮 Premium pixel-art inspired UI
- 🌙 Dark & Light theme
- 📱 Fully responsive design
- 🏋️ Workout cards
- 📚 Exercise library
- 🔍 Live exercise search
- 🎯 Difficulty filter
- ❤️ Favourite exercises
- 🧮 BMI Calculator
- 💾 localStorage persistence
- 🪟 Exercise detail modal
- 🍞 Toast notifications
- 📊 Animated statistics counters
- 🎨 Smooth UI animations
- ♿ Keyboard accessibility
- 🚀 Progressive Web App (PWA) support
